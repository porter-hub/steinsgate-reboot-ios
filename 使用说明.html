把命运石之门reboot 装到 iPhone

用你自己的游戏文件和 prod.keys，在这台电脑上做出 iPhone 安装包。全程在本机完成，不上传任何东西。

0需要准备

游戏文件STEINS;GATE 重制版（中文版）的本体 NSP 和 1.0.3 更新 NSP，从你自己的 Switch 导出。只支持 NSP，不支持 XCI。
密钥同一台 Switch 导出的 prod.keys。
iPhoneiOS 26 以上，A14 或更新的芯片（iPhone 12 及之后）。只在 iPhone 17 Pro 上实测过；内存小的机型可能不稳定。
电脑Windows 10/11（x64）、Apple 芯片的 Mac，或 Linux（x64 / arm64）。约 15 GB 空闲磁盘空间。第一次运行要联网（自动准备工具）。
Apple ID免费的就可以，用来给安装包签名。

1放文件

把两个 NSP 和 prod.keys 放进 「把游戏文件放这里」 文件夹。文件名随意，工具按内容识别；放了别的游戏也没关系，会被跳过。
App 图标默认用游戏自带的图标。想换成自己的图，把它命名为 icon.png（或 icon.jpg，正方形最好）一起放进去。

2运行「开始」

双击 开始-Windows.bat。如果 Windows 提示「已保护你的电脑」，点「更多信息 → 仍要运行」。
双击 开始-Mac.command。如果 macOS 说「无法验证开发者」而不让打开：打开 系统设置 → 隐私与安全性，在页面底部点「仍要打开」，再双击一次。（或者打开「终端」，输入 bash 后把这个文件拖进去，回车。）不需要 Xcode。
在终端里运行 bash 开始-Linux.sh。

工具会先逐项检查环境。缺 uv（用来准备 Python）或 .NET 10 运行时 时，它会问你要不要用官方安装脚本装上（装在你的用户目录，不需要管理员权限）。回答 Y 就好；也可以按提示自己去官网装。

然后自动完成：校验文件 → 解包 → 改写游戏程序 → 翻译着色器 → 组装安装包。大约 5–10 分钟，最后一行是 PACK OK。

中途出错时会用红字写明原因。解决后再运行一次，已经做好的步骤会自动跳过。

完成后，「输出」 文件夹里有两样东西：
SteinsGate.ipa —— iPhone 安装包（约 45 MB）
游戏数据 —— 文件夹，里面是 6 个左右的 .tar 文件（共约 5.8 GB）

3打开 iPhone 的开发者模式

iPhone：设置 → 隐私与安全性 → 开发者模式 → 打开，按提示重启。（看不到这一项时，先做下一步，装过一次以后就会出现。）

4用 Sideloadly 安装

  1. 从 sideloadly.io 下载安装 Sideloadly。Windows 还需要网页版 iTunes 和 iCloud（Sideloadly 官网有链接；不要用 Microsoft Store 版）。
  2. 用数据线连上 iPhone，在 iPhone 上点「信任此电脑」。
  3. 把 SteinsGate.ipa 拖进 Sideloadly，填你的 Apple ID，点 Start，按提示输入密码。
  1. 从 sideloadly.io 下载安装 Sideloadly。
  2. 用数据线连上 iPhone，在 iPhone 上点「信任此电脑」。
  3. 把 SteinsGate.ipa 拖进 Sideloadly，填你的 Apple ID，点 Start。
Sideloadly 没有 Linux 版。可以把 SteinsGate.ipa 和 romfs 拷到一台 Windows 或 Mac 上按那边的步骤装；或者用 AltServer-Linux 等第三方工具（未经测试）。
装好后，iPhone：设置 → 通用 → VPN 与设备管理 → 点你的 Apple ID → 信任。

5把游戏数据拷进 App

打开 iTunes（上一步为 Sideloadly 装的网页版）→ 左上角的 iPhone 图标 → 文件共享 → 选 命运石之门reboot → 把「游戏数据」文件夹里的所有 .tar 文件拖到右边的文档列表里，等进度走完。
Windows 11 装了「Apple 设备」App 的话：选中 iPhone → 文件 → 命运石之门reboot，同样拖进去。
打开访达 → 侧边栏选中这台 iPhone → 文件 → 把「游戏数据」文件夹里的所有 .tar 文件拖到 命运石之门reboot 上，等进度走完。
Linux 没有官方的文件共享。可以用 libimobiledevice 的 ifuse --documents <App 的 bundle id> 挂载点 把 .tar 文件拷进去（未经测试），或换到 Windows / Mac 上拷。
拷完后打开 App（已经开着的话先从多任务里关掉）：第一次会先「导入游戏数据」，约半分钟，导入后 .tar 文件会自动删掉。没拷数据就打开 App，会看到一屏说明。

6开始玩

打开 App。第一次启动会依次显示「正在导入游戏数据」「正在准备着色器」（共约一分钟，只有这一次），然后进入游戏。
屏幕右侧（灵动岛在右时是左侧）有两个常驻小按钮：⚙ 设置、🎮 呼出虚拟手柄。单击 = A，双击 = B，单指拖动 = 方向。

7以后

  • 7 天后打不开了？免费 Apple ID 的签名只有 7 天。用 Sideloadly 再装一次 SteinsGate.ipa 即可，存档和游戏数据都会保留。不要先删 App（删 App 会连存档一起删）。
  • 装不上，提示 App 数量上限？免费 Apple ID 在一台设备上最多同时装 3 个自签名 App，先删掉一个别的。
  • 存档备份：游戏内 ⚙ 设置 → 存档 → 导出。
  • 换一台 iPhone：不用重新打包，同一个 SteinsGate.ipa 和「游戏数据」里的 .tar 直接用。

本工具只提供程序和一个不含游戏内容的空壳；游戏内容全部来自你自己的文件，只在你的电脑和 iPhone 上。请勿分发做好的安装包或游戏数据。第三方组件的许可证见 kit/LICENSES。
