# 命运石之门reboot：iPhone 安装工具

用你自己的 Switch 游戏文件（STEINS;GATE 重制版中文版的本体和 1.0.3 更新 NSP）和 `prod.keys`，在 Windows、Mac 或 Linux 电脑上做出 iPhone 安装包，再用 Sideloadly 装到 iPhone。

1. 把两个 NSP 和 `prod.keys` 放进「把游戏文件放这里」。
2. 运行「开始」：Windows 双击 `开始-Windows.bat`，Mac 双击 `开始-Mac.command`，Linux 运行 `bash 开始-Linux.sh`。
3. 按「使用说明.html」装到 iPhone。

这个仓库里没有任何游戏内容（程序、美术、文字、声音、着色器、密钥都没有）。游戏相关的一切都在你的电脑上、用你自己的文件现做，做好的东西只在你的电脑和 iPhone 上，请勿分发。第三方组件的许可证见 `kit/LICENSES`。
